# Project Management & Agent Workflow Lab

A working collection for AI agent workflows, developer tools, interview preparation, and reusable skills. It combines original experiments and utilities with upstream and community frameworks, so parts of the repository differ in source, maturity, and maintenance.

## Featured project

[`resume-job-search-agent`](./package.json) is a TypeScript project for AI-assisted resume scoring and job search. Its package describes multi-board integrations. See `src/`, `scripts/`, and `tests/` for the implementation.

## Other areas

- `interview-prep/` — interview preparation material and workflows.
- `claude-flow/`, `.claude-flow/`, and `.swarm/` — agent orchestration experiments and configuration.
- `Skill Library/`, `skills/`, and `Skill_Seekers/` — reusable skills and skill discovery resources.
- `SuperClaude_Framework/`, `everything-claude-code/`, and `awesome-claude-skills/` — framework and community project collections.
- `_archive/` — historical experiments.

## Working with the repository

This is a collection, not one installable product. Read the documentation and package files for the specific project you plan to use; a root-level command may not apply to nested projects. Keep credentials in local, ignored environment files and use `.env.example` only as a template.
